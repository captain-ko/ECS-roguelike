This is a python entity component system roguelike I've been working on in my spare time. It isn't close to done yet, but a lot of important features are already there, like the graphics rendering and dungeon generation algorithm. The main systems are basically done, but what remains to be added is enemies, item inventory management, and a final goal for the dungeon. Right now it's more of a tech demo, but I'm sure after some more development I have some very interesting gameplay ideas.
